Daniel Game Cinematic Universe (DGCU)
A "simple" explanation of how all my projects fit together.
------------------------------
"Spin the Box (W3Schools Version)"
This is the main version of Spin the Box.
It’s where development happens first, because it’s fast, easy to edit, and perfect for testing new ideas.

Updates happen here before anywhere else

New features appear here first

This is the “live dev” version

The game grows here over time

This is the core of the project.
-------------------------------
"Spin‑the‑Box (GitHub Version)"
This is the stable release of Spin‑the‑Box.
It receives updates after the W3Schools version has been tested and confirmed working.

- Slower updates

- More stable

- Public release version

- Mirrors the W3Schools version eventually

Think of it as the official version of the game.
--------------------------------
"CommandCore"
A completely separate game, created later.
It is NOT Spin‑the‑Box, NOT S.T.B, and not connected to the Spin‑the‑Box gameplay.

CommandCore has:

- its own mechanics

- its own world

- its own rules

- its own chaos

It stands alone as a different project in the DGCU.
----------------------------------
"S.T.B (Link Version)"
S.T.B is a lighter, web‑friendly version that simply links to Spin‑the‑Box.
It is not a full game — it’s more like a portal or launcher.

Connects to Spin the Box

- Shares the same name

- Not the same as CommandCore

- Not a sequel

It exists to make Spin the Box easier to access.
-------------------------------
